## 💡 Pourquoi ces sujets ?

Les mesures DAS produisent des volumes importants de signaux spatiotemporels. Leur exploitation soulève des questions intéressantes : **comment mieux extraire une information utile de signaux bruités, localiser les événements, reconnaître les signatures vibratoires et améliorer les modèles lorsqu'on dispose de peu de données annotées ?**

Chaque PDF présente un sujet distinct. Consultez l'offre correspondante pour connaître le contexte, les objectifs et les compétences attendues.

## 🎓 À qui s'adressent ces stages ?

Ces thèmes peuvent intéresser des étudiants et étudiantes en **traitement du signal, data science, machine learning, informatique scientifique, mathématiques appliquées ou physique**. Les prérequis exacts sont à vérifier dans chaque offre.
